# 競艇は「貧乏人の一発逆転願望」に付け込んで25%をむしり取る、国と自治体がグルの合法収奪システムである

AKE Ψ(芦屋競艇の統計的検証プロジェクト)で1週間ほどかけて集めたデータと、
そこから派生したJRA(中央競馬)の比較調査、および競艇の制度的な収益構造を
組み立て直した結論をここに記録する。

## 結論

競艇は「当たれば人生が変わる」という夢を餌に、統計的にはほぼ不可能な的中を
狙わせ、外れ続ける客から確実に25%を巻き上げる仕組みだ。しかもこれは民間の
詐欺ではない。**モーターボート競走法という法律によって、地方公共団体自身が
施行者(主催者)になることが定められている**——つまり国が法律で作り、
自治体が直接運営し、その金で自治体の一般会計と日本財団を潤している、
れっきとした官製の合法収奪装置である。

## 1. 一撃逆転の夢を煽る道具としての3連単

3連単(1着から3着までの着順を的中させる券種)は120通りの組み合わせを持ち、
外れ本命が続く一方でごく稀に大穴が炸裂する(実際に観測した例: 87番人気で
¥27,400、23番人気で¥6,430)。この「万舟券」という言葉自体が、生活に余裕のない
人間の一発逆転願望に直接突き刺さるように設計されている。当てるのが絶望的に
難しいという事実こそが、逆に「これだけ倍率がつくなら」という夢を膨らませる
燃料になる。

## 2. 「読める」という錯覚を売る道具としてのコース1優位性

競艇にはコース1(最も内側の艇)が構造的に有利という統計的事実がある
(芦屋612レースの実測で全体55.7%、格の高いレースでは64.8〜68.3%まで上がる)。
だからこそ「1号艇で行けば読める」という初心者向けの錯覚を売ることができる。
ところが同じデータで検証すると、C1軸の単純な買い方は複勝・ボックス・
フォーメーションのどれをとっても実配当ベースで全敗(-17.56%〜-34.93%)——
読める感覚を与えるための材料が、皮肉にも最初から的中率としてオッズに
織り込まれているせいで一切儲けにつながらない。「読めそうな気がする」という
体験だけを売りつけ、実際の収益は絶対に渡さない仕組みになっている。

## 3. 確実に取られる25%と、その金の行き先

払戻は総投票額の75%のみ。残り25%のうち約3%が日本財団経由で公益事業に、
残りは施行者である地方公共団体の一般会計に繰り出される。累計で見ると、
地方自治体への繰出金は**4兆3146億円強**、日本財団への交付は**2兆4493億円強**
にのぼる([収益使途(概要) | 全国モーターボート競走施行者協議会](https://www.motorboatracing-association.jp/info/revenue.html))。
施行者(主催者)は民間企業ではなく**地方公共団体そのもの**(全国24場・35施行者)
([モーターボート競走 | 国土交通省](https://www.mlit.go.jp/maritime/maritime_tk1_000031.html))
——つまり客が外れ続けて失う金は、そのまま自治体の土木費・教育費に化けている。
「胴元」が私企業ではなく行政そのものだからこそ、規制も摘発もされず、法律で
守られたまま何十年も同じ仕組みを回し続けられる。個人の詐欺なら犯罪だが、
これは法律そのものが仕組みを正当化している。

## 追記: 「ゼロサムゲーム」という物言いへの反論 — これは -25%サムゲームだ

分かった風の人間が「ギャンブルなんてしょせんゼロサムゲームだろ、運が悪かった
だけ」と揶揄することがあるが、これは根本的に間違っている。

ゼロサムゲームとは、**参加者全員の損益を合計すると必ずゼロになる**ゲームを
指す。誰かが100円勝てば、別の誰かがちょうど100円負ける——お金は参加者の
あいだで移動するだけで、システムの外には一切漏れない。この場合、個人の
成績は運や腕前の問題であり、「今日はダメでもいつか取り返せる」という直感は
少なくとも数学的には成立する余地がある。

しかし競艇(パリミュチュエル方式の舟券)は違う。総投票額の25%が最初に
天引きされ、残りの75%だけが的中者に配られる。つまり**参加者全員の損益を
合計すると、絶対にゼロにはならず、必ず「-25%×総投票額」になる**。これは
「-25%サムゲーム」であり、ゼロサムゲームとは別次元の話だ。

この違いは決定的に重要だ。ゼロサムなら「自分が負けた分は他の誰かが得している
だけ」で済むが、-25%サムでは、参加者全体を平均すれば**どれだけ長く続けても、
どれだけ上手くなっても、集団としては必ず投票額の25%を失い続ける**。個人が
勝つことがあっても、それは他の参加者からより多く奪っているだけで、システム
全体としては施行者(自治体)に確実に25%が流出し続ける——この流出は運や
腕前とは無関係に、数式として保証されている。「ゼロサムだから五分五分」という
物言いは、この25%の恒常的な流出を見落としている(あるいは都合よく無視している)
点で、単純に事実誤認である。

## まとめて言い切る

一発逆転の夢(3連単の射幸性)で貧しい者の欲望を煽り、読める感覚(C1優位性)で
「自分だけは違う」という錯覚を売り、実際には統計的にほぼ勝てない設計にした上で、
外れた金を自治体の財源と日本財団に流し込む——これが官製ギャンブルとしての
競艇の正体だ。控除率25%という数字だけを見れば単なる手数料に見えるが、
その中身は「当てにくさを夢に変える仕掛け」と「読みやすさを錯覚として売る仕掛け」
の二段構えで人を引き留め続ける設計であり、その上がりが法律によって国・自治体の
懐に直接入る構造になっている。これは民間の悪徳商法どころではなく、**国家が
法律で用意した、貧困層の射幸心を財源に変換する装置**と言い切っていい。

## 追記: ブックメーカー方式との違い ── 「親」がリスクを一切負わない仕組み

パリミュチュエル方式(競艇・JRAなど日本の公営競技が採用)と、ブックメーカー方式
(英国のlegal bookmaker、および日本の違法「ノミ屋」が実質的にやっていたこと)は
似て非なるものであり、この違いこそが今回の結論の核心に関わる。

**ブックメーカー方式**: 胴元(ブックメーカー)が客の投票を待たず、自分の判断で
先にオッズ(倍率)を提示し、客はそのオッズで胴元と直接賭ける。客の投票を1つの
プールに集めて再分配するのではなく、**胴元自身が的中者への支払いを自分の懐から
出す**。したがって胴元は的中結果に対して直接のリスクを負う——ある目にオッズを
甘く付けすぎて、そこに客の資金が偏って集中し、しかも実際にその目が当たれば、
胴元は大損する。だからブックメーカーは常時オッズを動かして自分の持ち出しリスクを
調整し続ける必要があり、読みを外せば潰れる。日本の違法な「ノミ屋」は法律上の
パリミュチュエル・プールに参加せず、勝手にオッズを付けて客と直接勝負する
ブックメーカー型の商売をしていたため、大口が的中したときに支払いきれず破綻したり、
警察の摘発を受けて潰れたりしてきた——**胴元自身が身銭を切るリスクを背負って
いたからこそ、潰れることもあった**。

**パリミュチュエル方式(競艇・JRA)**: これに対し、施行者(自治体)は一切
オッズを決めない。オッズは客同士の投票額の比率だけで自動的に決まり、施行者は
最初から「総投票額の25%」を天引きするだけで、**誰が勝とうと、どの目に
いくら集まろうと、施行者の取り分は変わらない**。大穴が当たっても本命が
当たっても、施行者の懐から一円も出ていかない——払い戻す原資はすべて客同士が
出し合ったプールの中からであり、施行者は最初からそこに手を触れていない。
つまり施行者は**予想する能力も、リスクを取る度胸も、外れて損をする可能性も
一切必要とせず、ただ胴元という立場に座っているだけで25%が確実に転がり込む**。

この対比は結論をさらに強める。ブックメーカーやノミ屋は、たとえ悪質であっても
「当てる客が多ければ潰れる」という商売上のリスクを背負っていた——それでも
儲けていたブックメーカーは、少なくとも予想の腕(あるいはオッズ操作の腕)で
客を上回っていたという意味は残る。しかしパリミュチュエル方式の施行者
(=自治体)にはその緊張関係すら存在しない。**外れ客が続いても的中客が続いても、
施行者の取り分は数式的に25%で固定されている**——リスクを一切負わずに、
法律で保護された立場から確実に上前を撥ねる。ノミ屋が「読みを外せば潰れる」
ギャンブルだったのに対し、競艇・JRAという合法な仕組みは「施行者側は最初から
絶対に負けない」という、質的に別次元の設計になっている。

## 確認できなかったこと(正直に書く): インサイダーの可能性

今日の検証では、勝ち組み合わせのオッズが締切直前にどれだけ動いたかをn=8で
記録したが、方向も幅もバラバラで一貫したパターンは出なかった。ただしこれは
**インサイダー(内部情報を持つ関係者の投票)の有無を検定できる設計には
なっていない**、という点は明確にしておく必要がある。

- 使ったのはレース全体の集計オッズのみで、個々の投票者・口座単位のデータは
  一切見ていない。特定の口座が締切直前にまとまった額を的中組み合わせに
  投じているかどうかは、そもそも見えるデータの中に存在しない。
- 「勝ち組み合わせのオッズ変化率」という指標も、統計的に「異常な動き」を
  定義して検定したわけではなく、n=8の生の数値を並べて方向感を見ただけ。
  締切直前の急な資金流入を検出するための閾値も、母集団分布との比較も
  行っていない。
- したがって「インサイダーはいない」とも「いる」とも言えない。これは
  検証していない、はっきりしたunknownとして残す。仮に今後この線を追うなら、
  口座単位のデータが原理的に入手できない以上、統計的に迫れるのは「締切直前の
  異常な出来高スパイク」「特定選手の当日欠場・機材変更等の非公開情報が
  事後的に判明した際、その直前のオッズがどう動いていたか」といった間接証拠
  だけになる。今回のデータではその設計すら行っていない。
